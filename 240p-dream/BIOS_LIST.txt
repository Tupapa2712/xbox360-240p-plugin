===============================================================================
  240p Dream — Required & Optional BIOS Files List (Standard RetroArch BIOS)
===============================================================================

IMPORTANT:
  - NO BIOS files or game ROMs are included in this package.
  - Because 240p Dream uses standard Libretro cores (fork of Salvia 360),
    it uses the EXACT SAME BIOS files and filenames as RetroArch!
  - Obtain your own legally dumped BIOS files and place them inside:
        240p Dream\system\

Systems that DO NOT require a BIOS (work out of the box with your ROMs):
  - SNES / Super Famicom (Snes9x2010 / Snes9x)
  - NES / Famicom (Nestopia — only Famicom Disk System needs disksys.rom)
  - Sega Mega Drive / Genesis / Master System / Game Gear (Genesis Plus GX)
  - Game Boy / Game Boy Color (Gambatte)
  - Virtual Boy (Beetle VB), WonderSwan (Beetle WSwan), Neo Geo Pocket, C64
